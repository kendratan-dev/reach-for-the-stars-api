# API Reference - Reach for the Stars API

Base URL: /api/v1

## Endpoints Summary
- **GET /health**: System health check.
- **GET /game-info**: Build and author metadata.
- **GET /results**: Completed game results for Library Hub.
- **POST /auth/register**: Register a new player account.
- **POST /auth/login**: Authenticate and receive JWT Bearer token.
- **GET /auth/me**: Retrieve current authenticated user profile.
- **GET /users**: List all users (Admin).
- **PATCH /users/:id/role**: Update user role (Admin).
- **GET /question-sets**: Paginated list of question sets.
- **POST /question-sets**: Create a question set.
- **GET /sessions**: Manage game sessions and gameplay progression.
